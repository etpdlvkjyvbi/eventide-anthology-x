## Overview

Eventide Anthology X bundles emulations of Eventide's most celebrated hardware processors—H910, H3000, Omnipressor, and more—in a comprehensive collection.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Eventide Anthology X** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Hardware Bundle** | All major Eventide hardware emulations in one collection |
| **H910/H3000** | Classic Harmonizer pitch shifting and delay |
| **Omnipressor** | Legendary dynamics processor with unique gain and expansion |
| **Residual Algorithms** | Additional effects algorithms from vintage Eventide hardware |
